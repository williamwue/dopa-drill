## 下一个 agent 的执行入口

另一台电脑没有仓库时，在合适目录执行：

```sh
git clone --single-branch --branch zh-cn-preview https://github.com/williamwue/dopa-drill.git
cd dopa-drill
```

已有仓库时，先核对 `git remote -v`、`git status --short --branch`，保留本机已有修改；执行 `git fetch origin`，选择跟踪 `origin/zh-cn-preview` 的分支并仅以快进方式更新。若已有分歧或未提交修改，先检查再处理，不强制重置。
