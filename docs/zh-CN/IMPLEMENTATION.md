# 第一轮：简体中文体验版

## 范围与基线

上游 grmchn/dopa-drill，基线 fdacd5fc8322f251f92ddc07f13ae85ccb2263dd；原有 58 项 Node 测试通过。
原版文档语言 ja，用户可见文案散布 HTML 和各模块，课程年级与计时耦合。原版缺少中文语言目录、课程配置 API 和中文验收路径。

目标：中文默认、保留日语，完整练习体验、课程映射独立、原存档兼容、预览部署。暂不加入账号、数据库或教材内容。

## 结构与取舍

- `app/js/i18n.js` 提供 flat-key 字典及参数插值，界面、技能与学习内容分目录维护。
- 语言通过 `?lang=zh-CN` / `?lang=ja` 选择；设置切换后刷新，以统一模块初始化时的语言，不更改原存档。
- HTML 使用 `data-i18n` / `data-i18n-aria-label` / `data-i18n-content` 绑定。带标记的消息仅限仓库维护的可信模板，不接收用户 HTML。
- 保留技能 ID、题目内部答案及签名；中文显示与内部数据分开。
- 通用课程来自原项目编排，不代表中国教材。课程配置负责教材位置，技能计时配置负责难度。
- 系统中文字体优先，避免日文字体子集缺字。

## 吞吐检查点

阻塞门：字典键与插值参数一致、旧测试通过、旧存档兼容、手机与桌面主要路径通过、部署目标校验。
独立工作：根负责 i18n/HTML/main/guide/CSS；内容工作者负责题目/进度/奖杯/任务文案；课程工作者负责 skills/scoring/curricula。
写入隔离：各工作者使用独立 Git worktree 与明确文件所有权，根检查 diff 后 cherry-pick。只有根运行集成验收与发布。
共享状态：稳定字典接口、原技能 ID 和存档格式；接口变化先协调再集成。无模型调用、数据库或生产密钥。
