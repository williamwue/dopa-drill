- 小学：苏教版三年级数学上册，采用网络资料标识为 2025 秋启用的新教材目录。

## 三年级上册：适配清单

| 单元 | 现有能力 | 下一轮处理 |
| --- | --- | --- |
| 一 混合运算与数量关系（一） | g4-order 有四种含乘法的两步算式，没有除法混合运算 | 拆分有无括号及乘除法子技能；增加整除混合运算；数量关系应用题单独标覆盖状态 |
| 二 两、三位数乘一位数 | g2-mul-tens、g3-vmul-2x1、g3-vmul-3x1 可复用部分生成逻辑 | 校准整百数、连续进位、中间和末尾含零的覆盖，不能仅改年级标签 |
| 三 数据的收集与整理 | 无对应交互 | 首批不覆盖 |
| 四 毫米、分米和千米 | 无单位换算生成器 | 后续新增单位换算专项 |
| 五 平移、旋转和轴对称 | 无对应交互 | 首批不覆盖 |
| 六 两、三位数除以一位数 | g3-div-tens、g4-vdiv-2d1、g4-vdiv-3d1 可复用部分生成逻辑 | 校准商的位数、商含零、整除与余数；建立独立子技能 |
| 七 数量关系的分析（一） | 无完整应用题交互 | 后续新增情境与分步列式 |
| 八 观察物体（二） | 无对应交互 | 首批不覆盖 |

综合与实践、期末复习不计为额外计算单元。首批仅声明第 1、2、6 单元中的计算专项，不声明这三个单元的全部教学目标已覆盖。

## 七年级上册：适配清单

| 章节 | 下一轮处理 |
| --- | --- |
| 一 数学与我们同行 | 活动内容首批不覆盖 |
| 二 有理数 | 优先新增正负数、相反数、绝对值、带符号四则运算；之后扩展乘方和混合运算；数轴另需图形交互 |

| 五 走进几何世界 | 首批不覆盖 |
| 六 平面图形的初步认识 | 首批不覆盖 |

## 实现顺序与验收

1. 新增有来源与覆盖状态的教材配置，保留 general-calculation；教材单元与技能难度、技能 ID 分离。某技能可作为多个单元的复习项，不能用唯一归属假设阻止后续扩展。
2. 三上先交付第 1、2、6 单元的计算训练；新增技能用独立 ID，旧进度不变。
3. 七上先交付有理数运算；先完成符号与分数输入、精确答案表示，再接入奖励与错题。整数和分数使用精确算术，避免浮点误判。
4. 教材入口显示已覆盖的具体技能，未覆盖单元明确标注；不把日文原版的三年级安排直接当作苏教版三年级。
5. 检查边界题（零、负数、符号组合、进退位、商含零、余数），回归旧存档及现有测试；手机实测每种新增输入方式，再更新体验站。

独立孩子档案属于另一个功能，目前未确认共用设备需求，不作为教材适配前置条件。下册需要另行核验目录，不能用旧版下册拼接。
